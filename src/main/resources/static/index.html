Demo Workflow Guide

Customer:

  1. Login as customer.
  2. Search specialists by keyword or available-only.
  3. Select a specialist.
  4. Select an available slot.
  5. Enter topic/notes.
  6. Create booking.
  7. Check price and PENDING status.

Manager:

  1. Login as manager.
  2. Load all bookings.
  3. Confirm booking.
  4. Manage categories, specialists, and slots.

Customer (after manager confirms):

  1. Load my bookings.
  2. Reschedule if needed.
  3. Wait for manager to confirm again.

Specialist:

  1. Login as specialist.
  2. Load my schedule.
  3. Complete confirmed booking.
